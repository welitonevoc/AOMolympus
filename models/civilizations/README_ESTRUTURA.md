## Categorias dentro de cada deus

| Pasta | Conteúdo |
|-------|----------|
| `aldeao/` | Vilão/cidadão dessa civilização (trabalhador base) |
| `unidade_militar/` | Infantaria, arqueiros, cavaleiros, heróis dessa civilização |
| `unidade_mitica/` | Unidades mitológicas (minotauro, anúbis, etc.) |
| `deuses/` | O deus maior como unidade épica invocável (Era T5) + deuses menores associados |
| `cidade/geografica/` | Terreno e paisagem característica do domínio desse deus |
| `cidade/fortresses/` | Fortalezas e muralhas |
| `cidade/barracks/` | Quartéis e edifícios militares |
| `cidade/temples/` | Templos e edifícios religiosos/favor |
| `cidade/houses/` | Casas e residências (população) |
| `cidade/towers/` | Torres de vigia e defensivas |
| `cidade/town_center/` | Centro Urbano (principal edifício) |
| `cidade/divine_altar/` | Altar Divino (pré-requisito para invocação T5) |
| `mapas/terrenos/` | Tipos de mapa/bioma associados a esse deus |
| `mapas/fauna/` | Animais e criaturas do ambiente |
| `mapas/flora/` | Árvores, plantas e vegetação |

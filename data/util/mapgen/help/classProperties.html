Class Properties

 

Every Grid Square Class has the following basic properties, displayed at the top in the property editor:

General:

  • Name: The name of the class in the list. All classes on a map must have distinct names, and the names should contain only letters and underscores ("_"). Age of Mythology could encounter an error if you use "weird" class names.
  • DisplayColor: The color the class is shown with in the grid layout view. Colors may be changed at any time, for example to let you import an image file more easily. Choose a color that makes sense to you. Different classes should have different colors.

Land Generation:

  • AreaGenerationMode: Either Land (plain terrain), Water, Cliff or Forest. Note: It is recommended that you only use Land and Water classes. Forests and cliffs are more effectively placed using sub-areas. Forests placed by a class will cover the entire area without any variance, and cliffs will look squarish and unnatural, and they will also appear in exactly the same place each game; if you add them as sub-areas instead, they will remain within the class but they will be placed randomly and in more natural shapes.
  • AreaTerrain: The type of land, water, cliff or forest to use.
  • BaseHeight: The altitude above (or under) sea level; sea level is 0.0, and most cliffs in Age of Mytholgy are not higher than about 10.0.
  • CliffSettings: For cliff areas. Read About Cliff Settings for more info.

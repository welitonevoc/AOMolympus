Editing Classes

 

Grid Square Classes represent the various climate zones on your map: plains, hilly areas, forest zones, seas, deserts, etc. They define an area's terrain, as well as sub-areas (forests, lakes, dirt patches, etc) and object groups (Settlements, animal herds, straggler trees, ruins, etc) present on it. Classes can be "painted" on the map using the map grid layout controls. They can also be exported and imported to files so you can use the same class in several maps.

The left of the screen contains the Grid Square Classes List. Click a class on it to select it. The buttons below the list are as follows:

New - Add a new class. Note: Classes can be renamed using the Property Editor - read below.

Delete - Delete selected class.

Copy - Add a new class which is a copy of the selected class.

Export to File - Save selected class as a .mgc file, which you can load into another MapGen map or share with other map makers if you want.

Import from File - Load a saved class from a .mgc file.

Tip: You might find useful classes on the Internet if people who make them post them there to share with others. After you have a good "library" of classes built up, creating a map could be as simple as painting an image in less than 5 minutes and pressing Generate Map.

The middle of the sceen contains the Property Editor. This editor is used to change the selected class's settings and also add and modify sub-areas and object definitions. The two small buttons at the top can be used to list the class's properties in Categorized or Alphabetical order. Below these, the property editor displays several expandable "nodes". Click the + button on the left of a node to expand it, or the - button to collapse it. Many nodes contain sub-nodes, which can be expanded and collapsed in the same way. You can edit a node by clicking in the bold text area on the right of its name, or expanding it and editing the sub-nodes. Press Enter or switch to another node for your changes to take effect. The property editor also has a  help area at the bottom, which tells you about the meaning of the selected node.

All properties of your classes are set with the property editor. Read the sections below this one for help on each of them.

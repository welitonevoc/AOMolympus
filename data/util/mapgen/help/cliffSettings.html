About Cliff Settings

 

Cliffs are placed using several special parameters in MapGen maps. In general, using the default values (except for Height) is a good idea, though sometimes you might want to make a cliff without any ramps (EdgeSize 1.0) or with more of them (smaller EdgeSize, larger number of Edges). The cliff properties editable are as follows:

  • Edges: The number of impassable rock regions around the cliff's border. For example, a circular cliff with only one ramp up has one edge, while one with two ramps has two edges.
  • EdgeSize: The size, as a fraction of 1.0 (where 1.0 means the entire border is covered by impassable rock), of each edge. In total, EdgeSize x Edges should be less than or equal to 1.0.
  • EdgeSizeVariance: Random variance in EdgeSize.
  • Height: Height in meters above or below the sea level (the sea level is 0.0). Using a negative height will create a "canyon".
  • HeightVariance: Random variance in Height.
  • Steepness: How quickly the terrain rises or falls at the edge of a cliff. The default value of 0.9 is usually fine, but for taller cliffs you might want higher steepness.

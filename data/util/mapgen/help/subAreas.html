Sub-Areas

 

You can create smaller areas within the regions covered by each grid square class to add variation, terrain obstacles, or resources. While classes are placed exactly where the grid layout is painted with them, sub-areas are arranged randomly within the class they are placed on, letting your map be different every time although the general terrain features are the same in all games. For example, you could define a "mountains" class with several cliff sub-areas, and a "plains" class with a few forest sub-areas. If you paint the mountains class in the north of your map and the plains class in the south, there will always be cliffs in the north and a forests in the south, but the exact location of the cliffs and forests will vary each game. Sub-areas can overlap several grid squares of the same class, so they can be as large or winding as needed. To add sub-areas to a class, select it in the class list, and expand the Sub-Areas node. Click the "SubArea[] Array" and press the [...] button to add, remove and edit sub-areas, or, if you just want to add one area, increase the Count shown by 1. To edit an existing area, expand the Elements node.

Note that many of a sub-area's properties have a "min" and "max" value. Your map will have a random number within this range each time it is played. You can use this for randomization, so players have to scout around and adapt to the map conditions.

Each sub-area has the following properties:

General:

  • Name: The name displayed for the sub-area. Should contain only letters and underscores ("_"). Each sub-area within the same class should have a unique name.
  • Number: Number of areas to place for each 10,000 tiles covered by the parent class.
  • Size: The size of each area placed, in tiles.
  • Constraints: Rules to obey when placing this sub-area, so that it does not overlap with other sub-areas or come too close to various types of objects. Read About Constraints for more info.

Land Generation:

  • AreaGenerationMode: Either Land (plain terrain), Water, Cliff or Forest.
  • AreaTerrain: The type of land, water, cliff or forest to use. You can provide several types to randomly select between by separating them with a slash ("/"); for example, "SandA/SandB". For Land sub-areas, you can add "layers" around the sub-area to make it blend in smoothly with the surrounding terrain, using a comma (","); for example, "GrassDirt75,GrassDirt50,GrassDirt25,SandA" will make a smooth transition from grass with very little dirt in it to sand. You can combine randomization and layers: for example, "GrassDirt50,SandA/GrassDirt50,SandB".
  • Height: The altitude above (or under) sea level; sea level is 0.0, and most cliffs in Age of Mytholgy are not higher than about 10.0.
  • HeightBlend: How smoothly the area blends in with its surroundings; note that small areas will probably get flattened out completely if you use High.
  • Coherence: How much the area "clumps" together, as a number between 0.0 and 1.0. An area with Coherence 1.0 will be circular.
  • CliffSettings: For cliff areas. Read About Cliff Settings for more info.

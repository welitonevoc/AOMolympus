Placement Order

 

Terrain and objects on maps are placed by Age of Mythology in a specific order. It's important to keep this in mind when you are creating constraints - objects cannot avoid things that haven't been placed yet. The placement order is as follows:

  1. The map starts covered with the default terrain set in the global options.
  2. The area terrain of each grid square class is placed as specifid by the grid layout.
  3. Small player islands are created if the players start on water, and Town Centers or starting villagers/units are placed on these.
  4. Sub-areas of all classes are placed, in the order they are listed within each class.
  5. Object groups of all classes are placed, in the order they are listed within each class.
  6. Towers are placed if the players are to start with town centers and towers.

Tips and Tricks

 

Here are some general tips that will help you use MapGen:

1) There are pre-built classes of various Boreal, Temperate or Desert cimates, as well as three Water (ocean/sea) classes in the classes folder that came with MapGen. They're good starting places for making your own classes, and they can be used to make a map very quickly if all you want to do is create a map of your favorite area of the world and play there.

2) Use the following method to quickly edit and test maps:

  1. Open MapGen and either open an existing map file or create a new one and set its global settings and a script file to output to.
  2. Press Generate Map.
  3. Open Age of Mythology. Go to Options, and select Play in Window and a low resolution (800x600). Now you can easily switch between the game and the MapGen window.
  4. In Age of Mythology, go to More | Editor from the main menu. Then press File | New, select your script file's name, select a map size and Generate. You can now see all the details of the map.
  5. Make any changes you want in MapGen, generate the map and create it in the editor again as needed.

3) Use importing and exporting map images to your advantage. Many web sites and encyclopedia softwares let you view geographical maps of the world - you can paste one of these in Windows Paint, cut out the area you want, and import it into MapGen. Change classes' colors to those which most closely match the colors on the map for best results (you can always change them back later). You can also use Export Image to edit your map in Paint for more advanced drawing commands.

4) Share grid square classes with others, and save classes from your maps somewhere for use in other maps; the more pre-built classes you have at your disposal, the easier it gets to make new maps; all you have to do is paint them on.

5) Use constraints to your advantage. They are critical for ensuring resources are placed fairly, and they can also let you make more interesting situations.

6) Use layers around sub-areas to make them blend smoothly with the surroundings.

7) Before trying a map online, play it a few times in single player or with a friend, or just look at it in the editor, and check whether everything is placed fairly. The most important resources are Settlements and gold mines, but sometimes food, wood and building space can also be an issue.

8) Place players in such a way that their starting conditions are similar. For example, don't start some on water, some on plains, and some in a mountainous area - unless, of course, you want different starting conditions to be one of the features of your map.

9) You don't have to use MapGen only for real-world maps. You can also create fantasy worlds (maybe a part of Tolkien's Middle Earth?) or places from mythology or whatever you please. There's also an easy way to create a "regular" random map script like the Age of Mythology ones (Savannah, Alfheim, etc) with MapGen: just cover the entire map with the same class. You can add cliffs, forests and lakes to create variation. This is also a good way to test a particular class before using it on a map.

10) On maps with a lot of water, increase the map size or the amount of resources on land classes since fewer tiles will be covered with land.

11) You can maximize the MapGen window to edit classes more easily.

12) You can get pretty creative with object groups, constraints and sub-areas. For example, create a "farm zone" with fences, pigs, cattle, neutral Granaries and farm objects, or a "haunted forest" with bandits (neutral Toxotes or Throwing Axemen and some towers), or "volcanoes" using Underworld terrains. Try things out and you may stumble on something good.

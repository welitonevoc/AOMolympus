Map Files

 

MapGen uses two types of files to store maps: MapGen map descriptions and AoM random map script files.

MapGen map descriptions are stored in .mg files, which can be placed anywhere on your hard drive. They contain all of a map's grid square classes, as well as the layout information and global settings. They can be exchanged with other people who have MapGen. They cannot be opened by Age of Mythology itself however. You can save and open them using the Open, Save and Save As buttons at the top of the MapGen window.

AoM random map scripts (.xs files) tell Age of Mythology how to place terrain, units and triggers on a map. To create a script file for your map, first Open your .mg file, then select "Browse" at the bottom of the screen to select an output file, then press Generate Map. Script files must be saved in your Age of Mythology\rm directory (usually C:\Program Files\Age of Mythology\rm). Each .xs file also has an associated .xml file that must go with it for Age of Mythology to display it properly - both of these are created by MapGen when you press Generate Map. Script files can be used by any person with Age of Mythology. To play a game on your map, select Supremacy, Lightning, Death Match or Conquest as the game mode, and choose your map from the map selection screen. To distribute a map to someone, give them both the .xs and .xml files created. Script files also transfer automatically over multiplayer when a player in the game room doesn't have the map the host selected.

Note: It is very important that all random map scripts have a different filename. If two people have different versions of a script with the same name, they won't be able to play together on that script. When you make a new version of a script, give it a new filename.

Both map descriptions and script files can have any filename. The actual name Age of Mythology will display for your map is the "Map Name" you can set under Global Settings.

Note that while you can create a new script file from every MapGen map description file, you can't convert script files back to map descriptions. If you want to edit a map later, you should save the .mg file somewhere.
